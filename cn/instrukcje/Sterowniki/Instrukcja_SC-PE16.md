功率扩展器 SC-PE16 用于在负载超过上位控制器的承载能力时控制风机。设备根据模拟信号或手动设定值调节风机供电电压。最大总输出电流为 16 A。

![功率扩展器 ELETOR SC-PE16](./img/sc-pe16/sc-pe16.jpg)

## 参数与特性

- AUTO 和 MANUAL 模式以及设备休眠；
- 图形显示屏和触摸键盘；
- 2–10 V 或 4–20 mA 模拟控制；
- 可编程的第 2 通风组接通阈值；
- 在稳定的 100% 水平下启用 byPASS；
- 功率电路热保护；
- safeRUN：可设定的应急运行水平；
- 最低通风水平校准；
- 通风、继电器和报警测试；
- 键盘锁定和清洁锁定；
- 波兰语、英语或乌克兰语；
- 电源 230 V 交流，50 Hz；外壳 IP65。

:::info 软件版本

功能说明适用于随附的软件 **版本 2.1**。功能是否可用应以设备中安装的版本为准。

:::

## 控制器安装

:::danger 断开电源

安装设备时必须断开电源，因为某些组件上的电压会危及生命和健康。建议由具备资质的人员进行安装。

:::

### 安装位置选择

设备应安装在便于操作人员接近、儿童和动物无法触及且无阳光直射的位置。环境温度范围为 −10°C 至 +40°C。外壳和散热器周围应确保空气自由流通。不得遮挡散热器，也不得将设备安装在热源附近。

### 安装

利用密封腔外的安装孔，用四个膨胀锚栓将外壳底部固定在平整的墙面上。使用套件随附的铰链安装盖板。关闭前检查密封垫的状态和位置。

使用外截面为圆形且与电缆密封接头匹配的电缆。拧紧电缆密封接头，使其能够密封并固定电缆。封堵未使用的电缆入口。拧紧盖板上的所有螺钉。密封性取决于外壳和电缆入口是否正确安装。

### 接线准备

在外壳内部进行任何作业前，均须断开电源并确认无电压。如果拆卸面板需要断开排线，应小心将其断开，并在关闭外壳前重新插好。不得在通电状态下连接或断开排线。

INPUT 和 ENABLE 信号线应与电源线及输出线分开敷设。应遵循实际设备上标注的端子标识。信号输入地与保护接地端子 PE 的功能不同，不可互换。

## 电气连接

:::danger 断开电源

连接系统前，务必确认电源已关闭！

:::

![电源、风机、GR 2、ENABLE、CAN 和 INPUT 端子](./img/sc-pe16/zaciski.png)

| 端子 | 用途 |
| --- | --- |
| L, N, PE — 电源 | 电源 230 V 交流，50 Hz：L — 相线，N — 中性线，PE — 保护接地线。原始文档指定了 B20 保护装置；选择保护装置和电缆时应考虑安装条件及负载。 |
| U, N, PE — 风机 | U — 可调相线输出；N 和 PE — 设备相应的公共端子。风机电流之和不得超过 16 A。每台风机均需单独配置保护装置。应使用获准进行电压调速的电机。 |
| GR 2: C, NO | 第 2 组的隔离继电器触点。当设定通风水平等于或高于“第 2 通风组”阈值时，触点闭合。随附说明书规定的最大触点电流为：6 A。直接控制负载时，文档指定使用 B6 外部保护装置。 |
| INPUT: V, 地 | 电压输入。选择“控制类型 → V 输入”。所分析程序的调节范围为 2–10 V。不得将电网电压或风机可调供电输出连接至此输入端。 |
| INPUT: I, 地 | 电流输入 4–20 mA。选择“控制类型 → I 输入”。按信号源和接收端的标识连接信号。 |

控制时使用所选的 V 或 I 输入。SC-PE16 需要独立的电网供电；模拟输入仅传递控制值。

## ENABLE 输入与通信

### ENABLE: E 和地

该输入与无源触点配合使用。E 端子与地之间仅允许短接或断开；不得施加外部电压。短接允许运行，断开则将水平设定为 0%。停机受“降速时间”设定值控制。

ENABLE 功能在“高级 → 风机”菜单中针对 AUTO 和 MANUAL 分别启用。这两项功能出厂时均为禁用，因此此时无需跳线。断开 ENABLE 不等同于休眠：面板保持工作状态。在 AUTO 中，ENABLE 锁定生效时，程序跳过控制信号读取，且不启动 safeRUN。

### CAN 和 Wi-Fi

菜单中存在“CAN 输入”和“WiFi 输入”选项，但在版本 2.1 的软件中不执行控制：这两项功能均返回 0% 水平。使用此程序启动设备时，应选择 V 或 I 输入。未确认已安装软件版本支持 CAN 或 Wi-Fi 前，不得基于这两种通信方式配置系统。

## 工作原理

SC-PE16 是执行上位控制器或操作人员指令的功率调节器。它不测量室内温度，也不具备自身的温度、换气、辅助加热或进风挡板设定。通风水平百分比表示控制值，而非电机实际转速的测量值。

| 标称信号 | 设定通风水平 |
| --- | --- |
| 2 V / 4 mA | 0% |
| 6 V / 12 mA | 50% |
| 10 V / 20 mA | 100% |

在边界值之间，程序以线性方式确定水平，并四舍五入至整数百分比。对于 V 输入，读数超过 2,04 V 后水平开始上升；对于 I 输入，则在超过 4,04 mA 后开始上升。最终输出状态还取决于 ENABLE、启动过程和热保护。

## 应急运行与保护

### safeRUN — 输入信号丢失

在 AUTO 模式下，根据所选输入，当电压读数低于 1,50 V 或电流读数低于 2,00 mA 时，会出现“输入”报警。此时程序将水平设定为“应急运行”值，范围为 0–100%；出厂值为 30%。当信号恢复至检测阈值或高于该阈值时，输入报警解除，设备恢复模拟控制。

在 1,50–2,04 V 及 2,00–4,04 mA 范围内，水平为 0%，且不触发输入报警。在此版本中，0 V 信号并非普通的停止指令，而是会启动应急运行。输出为 0–10 V 的上位控制器应配置为 2–10 V 范围，不得切断至 0 V。在 MANUAL 中，模拟信号不控制通风，且输入报警被清除。

### 热保护

当散热器温度读数超过 87°C 时，触发“过热”报警。温度降至 80°C 以下后，报警清除。报警期间，程序会更改设定水平：对于不低于 50% 的值，设定为 100%；对于低于 50% 的值，设定为 0%。输出变化受启动和降速算法控制。该保护无法保证在所有情况下通风均持续运行。

GR 2 继电器状态在热保护修正前确定：其状态取决于强制设定为 0% 或 100% 之前的水平。应急运行水平同样受热保护修正影响。发生过热时，应检查冷却条件、散热器积污情况及负载；外壳内部的作业应交由具备相应资格的人员执行。

### byPASS 与软启动

当输出水平稳定在 100% 时，程序接通相位调节电路的旁路继电器。启动过程可包括上升至 100%、保持在 100% 以及过渡至设定水平。“软启动”参数还会影响输出对请求值变化的响应速度。

## 控制器首次启动

:::warning 风机校准

注意！首次启动设备时，必须设置电机运行禁区。

:::

1. 在电源断开的情况下，检查电源、PE、风机及模拟信号的连接。确认电机获准进行电压调速，且总电流不超过 16 A。
2. 接通电源。若出现语言选择提示，按 OK 并选择语言。使用带挂锁符号的按键解锁键盘。
3. 在“控制类型”中选择“V 输入”或“I 输入”。设置“应急运行”水平和“第 2 通风组”阈值。如有需要，为相应模式单独启用 ENABLE。
4. 进入“高级 → 风机 → 禁区”。在此选项中，程序强制设定为 1% 水平，参数更改会立即影响输出。范围为 −20 至 200，出厂值为 0。正值提高最低控制水平，负值降低最低控制水平。
5. 调整数值，使所有风机均能稳定转动，无停转或过度发热。观察每台风机，最好由另一人协助。仅观察挡板抬起不能代替检查电机是否正常运行。按 OK 确认；按 ESC 恢复先前设定。
6. 在多个水平下检查输出，包括 0%、低水平和 100%。更换风机或改变风机配置后，应重新校准。
7. 在 AUTO 中检查对最小和最大信号的响应。随后检查信号中断时是否切换至应急运行，以及信号恢复后是否恢复正常控制。如果 ENABLE 已启用，还应检查其功能。
8. 在“测试”菜单中检查 GR 2 及报警指示。测试结束后退出此选项，并选择目标运行模式。

:::warning 输出将实际启动

测试和校准会控制实际输出。它们可能启动风机，而通风测试会独立于正常控制强制设定水平。应确保测试条件安全，并全程监护。

:::

## 控制器编程

### 前面板 — 指示灯与按键

| 元件 | 操作 |
| --- | --- |
| 电源 / 休眠 | 按下带电源符号的按键会显示休眠确认提示；按 OK 确认。再次按下可唤醒设备。休眠会将输出设为关闭状态；不会断开电网电压。 |
| 挂锁 | 启用或解除键盘锁定。解锁后，挂锁旁的指示灯亮起。在主屏幕上，无操作约 30 s 后会重新锁定。 |
| A — AUTO | 按 OK 确认后选择模拟输入控制。A 指示灯表示所选模式。 |
| M — MANUAL | 按 OK 确认后选择手动控制。在主屏幕上，+ 和 − 键可在 0–100% 范围内更改设定值。M 指示灯表示所选模式。 |
| +, −, OK, ESC | OK 用于打开菜单、进入选项及确认数值。+ 和 − 用于选择选项或更改数值。ESC 用于返回上一级或取消编辑。 |
| 报警与第 2 组 | 红色指示灯表示报警。风机符号“2”旁的指示灯表示 GR 2 继电器已接通。 |
| 显示屏 | 在 AUTO 中，显示设定通风水平、所选输入读数、条形图及报警。ENABLE 启用时，还会显示其状态。在 MANUAL 中，主数值表示手动设定值；保护功能可能改变输出。 |

### 设定值保存

菜单参数在按 OK 确认后保存至非易失性存储器。MANUAL 水平的更改立即生效，并在短暂无操作后保存。电源中断后，设备恢复已保存的设置，包括 AUTO/MANUAL 模式、手动水平和休眠状态。更改手动设定值后，不得立即关闭电源。

若校验和错误或数值超出范围，程序将恢复出厂值。此时应重新检查所有设置，尤其是风机校准、控制输入和应急运行设置。

| 高级 | 子菜单 | 提供测试、语言、风机校准、ENABLE、软启动、报警声音、出厂设置及程序信息选项。 |

| 菜单 / 参数 | 范围 / 出厂值 | 说明 |
| --- | --- | --- |
| 测试 → 通风 | 0–100% | 临时强制设定可调输出。更改在编辑过程中生效。通过 OK 或 ESC 退出后恢复正常控制。 |
| 测试 → 第 2 级通风 | 否 / 是 | 临时强制控制 GR 2 触点及其指示灯。 |
| 测试 → 报警 | 否 / 是 | 临时测试报警指示，包括声音，不受正常“报警信号”设定值影响。 |

| 风机 → 禁区 | −20–200 / 0 | 校准 1% 水平。编辑期间会强制设定实际输出为 1%。该参数不以百分比或秒表示。 |
| 风机 → 启用 EN AUTO | 否 / 是；否 | 启用 AUTO 模式对 ENABLE 输入的依赖。 |

| 程序 | 版本 2.1 + 编译日期 | 显示程序版本和编译日期。本说明根据随附的 SC_PX16_v02 源代码编写。 |

软启动参数是程序计数器的无量纲设定值，并非以秒为单位的时间。在 50 Hz 下，单个步进约对应（设定值 + 1）× 20 ms：对于升速和降速，该值表示变化 1 个百分点的时间；对于“100% 时间”，则表示保持时间。值 0 的含义见表中说明。实际时间取决于算法所处阶段。

## 错误与警告信息

| 信息 | 含义与处理方法 |
| --- | --- |
| 输入 | 在 AUTO 中，所选信号读数过低。设备设定为应急运行。检查信号源、接线、公共地及 V/I 的选择。 |
| 过热 | 散热器读数 &gt;87°C；清除条件 &lt;80°C。按照热保护说明，通风设定为 0% 或 100%。检查冷却和负载。 |
| 电源 | 功率电路与电网同步异常。检查电源和电气安装。电源完全中断时，显示屏不工作。 |
| 存储器 CRC | 已保存设定值的校验和或范围错误。程序恢复默认值。检查配置并重新校准；若错误再次出现，请联系维修服务部门。 |

## 注意事项与警告

:::danger 断开电源

通风和应急运行设定应根据动物需求及安装条件选择。定期检查所有风机的实际运行情况。SC-PE16 指示不能代替对场所环境条件和断电情况的独立监测。所示端子排没有用于连接报警主机的独立 ALARM 触点。
